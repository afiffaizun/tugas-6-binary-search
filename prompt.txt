Buatlah program Binary Search Tree (BST) menggunakan bahasa pemrograman Java/Python dengan ketentuan sebagai berikut:

1. Program harus memiliki class Node yang berisi:

   * id (integer)
   * nama (string)
   * left dan right (pointer ke node lain)

2. Program harus memiliki class BST yang mendukung operasi:

   * Insert (menambahkan data berdasarkan id)
   * Search (mencari data berdasarkan id)
   * Delete (menghapus data berdasarkan id, termasuk kasus:
     a. tidak punya anak
     b. satu anak
     c. dua anak)
   * Traversal:
     a. Inorder
     b. Preorder
     c. Postorder

3. Program harus bisa membaca data dari file CSV dengan format:
   id,nama
   10,Andi
   5,Budi
   20,Siti

4. Tambahkan fungsi import_csv(path) untuk:

   * Membaca file CSV
   * Melewati header
   * Memasukkan data ke dalam BST

5. Program harus memiliki menu interaktif:

   1. Tambah Data
   2. Cari Data
   3. Hapus Data
   4. Tampilkan Inorder
   5. Tampilkan Preorder
   6. Tampilkan Postorder
   7. Import dari CSV
   8. Keluar

6. Program harus menangani error seperti:

   * File tidak ditemukan
   * Format data salah
   * ID bukan angka

7. Gunakan library bawaan Python (csv) tanpa library eksternal.

Tujuan:
Melatih pemahaman struktur data Binary Search Tree serta implementasi pembacaan file eksternal (CSV).

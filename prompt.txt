Buatkan program AVL Tree lengkap menggunakan bahasa pemrograman Java atau Python.

Spesifikasi program:

1. Gunakan konsep OOP (Object-Oriented Programming):

   * Class Node (atribut: id, nama, height, left, right)
   * Class AVL Tree (berisi semua operasi)

2. Implementasikan fitur berikut:

   * Insert data (dengan balancing AVL: LL, RR, LR, RL)
   * Delete data (dengan rebalancing)
   * Search berdasarkan ID
   * Traversal:

     * Inorder
     * Preorder
     * Postorder

3. Tambahkan fungsi pendukung AVL:

   * Menghitung height node
   * Menghitung balance factor
   * Rotasi:

     * Left Rotate
     * Right Rotate

4. Tambahkan fitur import data dari file CSV:

   * Format CSV: id,nama
   * Skip header
   * Validasi jika data tidak sesuai

5. Buat menu interaktif di terminal/console:

   1. Tambah Data
   2. Cari Data
   3. Hapus Data
   4. Inorder
   5. Preorder
   6. Postorder
   7. Import CSV
   8. Keluar

6. Gunakan input dari user (Scanner untuk Java / input() untuk Python)

7. Berikan full code yang bisa langsung dijalankan (tanpa error)

8. Tambahkan contoh file CSV dan cara menjalankan program

9. Gunakan kode yang rapi, mudah dibaca, dan beri komentar pada bagian penting

Output yang diharapkan:

* Full source code
* Penjelasan singkat cara menjalankan
* Contoh CSV
